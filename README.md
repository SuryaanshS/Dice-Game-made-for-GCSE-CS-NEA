# Multiplayer Dice Game

Welcome to my Python dice game built for **Stardance**! This is a two-player dice game where players log in, roll dice, and compete for a spot on the leaderboard.

Download the folder "src" and use the executable to run the code, or alternatively, use the link below.

## Live Demo
**[Click here to play the live game on Trinket!](PASTE_YOUR_TRINKET_LINK_HERE)**

## How to Play
1. **Rounds**: 5
2. **Rules**: 
   * If the sum of your two dice is **Even**, you get +10 points. 
   * If you roll **Doubles**, you get an extra dice roll!
   * If the sum is **Odd**, you lose 5 points.
   * The player with the highest total score after 5 rounds wins and gets saved to the Leaderboard.

## Test Login Credentials
To test the game, you can use the authorised accounts that can be found in the file **AuthorisedUsers.txt** on the Trinket link.

## Required Files

To run the game, ensure the following text files exist in the same folder as your executable or script:

1. **`AuthorisedUsers.txt`**: Formatted as `USERNAME,password` (one per line).
2. **`Leaderboard.txt`**: Created automatically on first win or pre-filled with previous score data.
